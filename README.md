## 📌 Project Description

**Driver Drowsiness Detection System** is a real-time computer vision application developed to detect signs of driver fatigue and drowsiness using a webcam.

The system continuously monitors the driver's face and eyes using **OpenCV** and **dlib facial landmark detection**. It analyzes eye movements by calculating the **Eye Aspect Ratio (EAR)** and identifies prolonged eye closure over consecutive frames.

When the system detects a potential drowsiness event, it automatically triggers an **audio alert** to warn the driver and help reduce the risk of fatigue-related accidents.

### 🎯 Key Highlights

* Real-time driver monitoring using a webcam
* Face and eye detection using computer vision
* 68-point facial landmark detection
* Eye Aspect Ratio (EAR) based drowsiness detection
* Detection of prolonged eye closure
* Automatic audio warning system
* Real-time processing using Python and OpenCV

### 🛠️ Technologies Used

**Python • OpenCV • dlib • NumPy • Haar Cascade • Facial Landmark Detection**

### 💡 Objective

The main objective of this project is to demonstrate how **computer vision and facial landmark analysis** can be used to build a real-time driver safety system capable of identifying potential drowsiness and providing an immediate warning.
